# 6-1: Array - Jawaban Praktik

## Kosakata
1. **Array traversal** — Tindakan menelusuri setiap elemen dalam sebuah array secara berurutan.
2. **Array** — Sebuah struktur yang menyimpan beberapa nilai dengan tipe data yang sama.
3. **Two-dimensional array (Array 2D)** — Array dua dimensi.
4. **Index** — Sebuah integer yang mengidentifikasi lokasi sebuah nilai dalam array.
5. **Command-line arguments** — Kemampuan untuk meneruskan data ke dalam fungsi `main` dan mengaksesnya sebagai elemen dari sebuah array.
6. **Algorithm** — Sebuah prosedur komputasi logis yang, jika diterapkan dengan benar, memastikan penyelesaian suatu masalah.
7. **Multidimensional array** — Sebuah array yang terdiri dari array-array lain, mirip seperti tabel, matriks, atau spreadsheet.
8. **Nested for loop** — Sebuah `for` loop di dalam `for` loop lainnya.
9. **Array** — Sebuah object bernama yang digunakan untuk menyimpan lebih dari satu nilai.
