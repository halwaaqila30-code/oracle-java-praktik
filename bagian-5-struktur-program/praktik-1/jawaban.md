# 5-1: Scanner dan Pernyataan Kondisional - Jawaban Praktik

## Kosakata
1. **Ternary operator (`? :`)** — Bentuk singkat dari pernyataan `if/else`.
2. **`Scanner`** — Class Java yang digunakan untuk membaca input dari keyboard atau file selama eksekusi program.
3. **Pernyataan Kondisional / Control Flow (`switch` & `if/else`)** — Jenis pengendalian program yang memungkinkan berbagai segmen kode untuk dieksekusi ketika nilai input cocok dengan kondisi yang diberikan.
